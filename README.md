# ITTY COMPANY — сайт челленджа

Участие бесплатное (1 шанс), каждый дополнительный шанс стоит $1, разыгрывается 5 мест.
Старт — 18 октября 2026, длительность — месяц, после этого публикуются итоги.

## Что внутри

| Файл | Что это |
|---|---|
| `server.js` | Сервер: регистрация, вход, оплата, админка, розыгрыш. Без внешних зависимостей. |
| `public/index.html`, `styles.css`, `app.js` | Сайт: таймер, призы, калькулятор шансов, регистрация, личный кабинет, итоги |
| `public/scene3d.js` | 3D-сцена на фоне (three.js): развевающиеся купюры, монеты, шары, бублики, кристаллы |
| `public/img/dollar.png` | Розовая купюра (прозрачный PNG). Замени файл с тем же именем — поменяется везде |
| `public/admin.html` | Админка по адресу `/admin`: таблица участников, проверка подписок, выгрузка в Excel, розыгрыш |
| `.env.example` | Все настройки: даты, призы, Instagram, цена, пароли, оплата |
| `data/db.json` | База данных (создаётся автоматически). **Делай резервные копии.** |

## Запуск на компьютере

1. Установи Node.js 18+ с https://nodejs.org
2. Скопируй `.env.example` в `.env` и заполни.
3. `node server.js` → открой http://localhost:3000, админка — http://localhost:3000/admin

Чтобы посмотреть сайт так, будто челлендж уже идёт, поставь в `.env` дату `START_AT` в прошлом.

## Как всё работает

**Фазы** (переключаются автоматически по времени из `.env`):
- до `START_AT` — обратный отсчёт до старта, регистрация закрыта (можно открыть заранее: `PREREGISTRATION=1`);
- `START_AT` → `END_AT` — идёт челлендж: регистрация и покупка шансов, таймер считает до конца;
- после `END_AT` — приём закрыт, ждём розыгрыша;
- после розыгрыша в админке — на сайте анимированно появляются 5 победителей.

**Подписка на Instagram.** Instagram не даёт сайтам автоматически проверять, подписан ли человек на аккаунт:
официального API для этого нет, а парсинг нарушает правила Instagram и приводит к блокировкам.
Поэтому проверка такая: участник указывает ник и подтверждает подписку, а ты в админке
нажимаешь ✓ или ✕ (ник в таблице — ссылка на профиль). **В розыгрыше участвуют только люди с ✓.**
Участник видит свой статус в личном кабинете.

**Номерки.** Каждый шанс сразу получает уникальный номерок: бесплатный — при регистрации,
купленные — сразу после оплаты (купил 10 — получил 10 номерков подряд, например #0120–#0129).
Номера идут по порядку и никогда не повторяются; если шанс списан, номерок помечается
«аннулирован», но его номер больше никому не выдаётся. Участник видит свои номерки сразу
после регистрации и оплаты, а все сразу — в личном кабинете.

**Розыгрыш.** Сервер случайно (криптографический генератор) выбирает 5 номерков среди участников
с подтверждённой подпиской. Владельцы выпавших номерков побеждают; один человек — одно место
(если выпал второй номерок того же человека, выбирается другой). Хэш списка номерков публикуется с итогами.

**Таблицы.** В админке три вкладки: участники (с их номерками), номерки (полный журнал по порядку:
номер, время, бесплатный/купленный, имя, email, Instagram, подписка) и платежи. Кнопки скачивают
файлы для Excel. Для **живой Google Таблицы** задай `EXPORT_KEY` в `.env` — в админке появятся
формулы `=IMPORTDATA("...")`: вставь в ячейку A1 новой Google Таблицы, и данные будут обновляться сами
(работает, когда сайт опубликован в интернете).

## Оплата

- `PAYMENT_MODE=demo` — шансы начисляются **без оплаты**. Только для теста!
- `PAYMENT_MODE=stripe` — реальная оплата через Stripe Checkout:
  1. В Stripe → Developers → API keys возьми `sk_live_…` и вставь в `STRIPE_SECRET_KEY`.
  2. Developers → Webhooks → Add endpoint: `https://ТВОЙ-ДОМЕН/api/stripe/webhook`,
     событие `checkout.session.completed`. Его signing secret вставь в `STRIPE_WEBHOOK_SECRET`.
  3. `PUBLIC_URL` = адрес сайта с https.

> ⚠️ **Важно до запуска.** Платные шансы на приз — это по сути лотерея. У Stripe и большинства
> платёжных систем лотереи и розыгрыши с платным участием в списке запрещённых или требуют
> отдельного согласования: аккаунт могут заблокировать вместе с деньгами. Во многих странах,
> включая Украину, проведение лотерей регулируется законом. Перед запуском обсуди формат
> с юристом и со своей платёжной системой. Код оплаты собран в одном месте (`/api/checkout`
> в `server.js`), так что подключить другую платёжную систему несложно.

## Публикация в интернете (например, Render.com)

1. Залей папку в репозиторий на GitHub (без `.env` и `data/` — они уже в `.gitignore`).
2. На Render: New → Web Service → выбери репозиторий. Build command — пусто, Start command — `node server.js`.
3. В разделе Environment добавь все переменные из `.env`.
4. **Добавь Disk** (Persistent Disk, например `/var/data`) и укажи `DATA_FILE=/var/data/db.json` —
   иначе база будет стираться при каждом перезапуске.
5. Подключи свой домен и пропиши его в `PUBLIC_URL`.

Подойдёт любой хостинг с Node.js и постоянным диском: Railway, Fly.io, VPS.
